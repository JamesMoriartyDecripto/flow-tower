# Release gates: Flow Tower v0.18.0

Release candidate: `release/v0.18.0`, on top of `main` at `13b749e` (#442), checked on 2026-11-03. Merged since v0.17.0: #433, #434, #437, #439, #440, #442.

A minor release: a phone layout for the tower view, project skills for the dev squad, and one security fix in the unattended runner's plan gate.

- **Security: a literal plan entry granted its folder without the sign-off** (#435, PR #440). `writeDirsFor` gives the coder the folder of every literal Files entry, so `tools/helper.mjs` let it write `tools/squad/`. A literal entry whose folder holds a control path now needs the plan sign-off, compared without case (macOS file systems ignore it).
- **Phone layout** (#436, PR #437). At 390 px the Layers panel, the tower card and the legend covered the whole tower and the bottom bar ran off screen. Under 600 px the view shows one panel at a time (Layers / Info / Legend tabs) as a bottom sheet; picking a layer or a node closes it; the bottom bar scrolls sideways; the mouse and keyboard hint is hidden. Wider windows are unchanged. A 390×844 e2e test checks it.
- **Dev squad:**
  - Project skills (#432, PR #439): `tools/squad/skills/<name>.md`, given to a role in `squad.json` `skills` or to one run by a task's `Skills:` line; names only, read through one descriptor with no link followed, size-capped, checked by `squad doctor`. With none set, prompts are byte-for-byte unchanged. This repo ships `bash-3-2`, `untyped-mjs` and `file-size`.
  - Reviewer findings carry the security severity scale, and a missing or unknown severity blocks the gate (#427, PR #433).
  - `run.mjs --base <rev>` sets the diff base for one run; the `diff` tool starts with the commit list (#425, PR #434).
  - The step-scope tests no longer inherit `SQUAD_ADOPT`, so a continued step's check is not RED for that alone (#438, PR #439).

This is a gate run, not a full audit: the finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not run again.

**Pre-merge reviews.** Every PR went through the review and security passes and the merge gate (READY), again after each fix. On record:
- **#439 (#432):** security asked to check and read each skill through one file descriptor, since a path checked with lstat and read again could be swapped for a link in between. Fixed before merge (`O_NOFOLLOW`, `fstat`).
- **#440 (#435):** security found that the folder check was case-sensitive while macOS file systems are not; fixed before merge. Its `.`/`..` spellings were already refused when the plan is parsed.
- **#437 (#436):** the e2e phone test first measured panels mid slide-in; it now shares the size tests' animation wait.
- **#442 (#441):** the first full e2e run of this release failed one older test (115/116): it expected the tower card open on a phone, which since #436 opens from the Info tab. The test was updated, then the gates and the full e2e ran again on the merged branch: this report and the logs are that second run.
