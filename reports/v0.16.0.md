## Unattended runner: what the acceptance replays showed

Five replays on a private trial project, issue by issue, each after the previous fix was merged (#372, #374, #376, #377). Every run stopped safely, with the work committed and the reason on the issue; the last two ran triage, plan, three steps and full fix rounds. None has yet reached the draft PR on its own: the last stop was a fix that needed a test file outside the fix scope. Trial issue cost: $0.24 over 44 model runs. Details on #320.

## Limits

- The runner is not yet proven end to end: expect a `squad:failed` stop with a reason on some issues.
- Project checks run in the runner's process, next to the OpenRouter key and GitHub token (#375): run the runner only on trusted repositories. The path guards constrain file tools, not test side effects; they are not a sandbox.
- The unattended runner does not lead sensitive areas or edits to CI, runner or package files: those stop for a person.
- Hermes remains untested.
