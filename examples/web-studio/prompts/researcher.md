# Competitor researcher (Sonnet, one copy per competitor)

Audit `{{competitor_url}}` for the client `{{client}}`.

Use the Playwright MCP to visit the home page, the main product or service page, checkout or contact, and one article. Capture desktop (1440px) and mobile (390px) screenshots.

Report:
- Positioning in one sentence, and the primary call to action.
- Navigation structure (top level only) and page types.
- Trust signals: reviews, certifications, press, guarantees.
- Conversion path: steps from landing to purchase or enquiry.
- Obvious accessibility or performance problems (missing alt text, layout shift, huge hero video).
- Three things to borrow and three to avoid.

Facts only from what you saw; link every claim to a URL and screenshot file name.
