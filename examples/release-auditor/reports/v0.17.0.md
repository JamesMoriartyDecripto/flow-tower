# Release gates: Flow Tower v0.17.0

Release candidate: `release/v0.17.0`, on top of `main` at `6d4edef` (#430), checked on 2026-11-02. Merged since v0.16.1: #395, #402, #408, #409, #410, #411, #413, #414, #415, #417, #418, #419, #421, #423, #428, #429, #430.

A minor release: two settings for the dev squad (`style` in `squad.json`, `SQUAD_ADOPT`), `emit --call`, fixes from a UX pass on the live view, and field reports from projects that run the squad.

- **Security: a glob plan entry could reach a control file without the sign-off** (#391, PR #408). `tools/*/runner-core.mjs` matched no control sample yet granted `tools/squad/runner-core.mjs` to the coder. A glob entry now needs the sign-off when a control path starts with its text before the first `*`; a plan also refuses `.` and empty path segments.
- **Server: the library server used up the system's file watchers** (#401, PR #402). It watched every file under its library folders (a Python venv, a data folder): 64,685 of 65,068 inotify watches, so other servers logged ENOSPC for every file. Measured after the fix on the same library: 4,937.
- **Live view, from a UX pass with simulated errors** (#397, #398, #400; PRs #409, #410, #411). The LIVE ERR chip and the feed header now count the same events; events that matched no node are reachable from the Tower scope; repeated errors fold into one row; a failed layer stays marked until Clear; live chips no longer cover each other. A mistyped CLI option prints one line instead of a stack trace, and `emit` takes `--call`.
- **Dev squad, from field runs on other projects:**
  - `squad.json` `style: { language, maxFileLines }`: prompts no longer say "English only" and "~400 lines" next to a project's own rules (#404, PR #415).
  - `SQUAD_ADOPT=<paths>` continues a red step; a step that names a kept-out path is RED instead of a partial green commit (#416, PR #430).
  - `steps.sh` runs on macOS bash 3.2 and keeps a project's git hooks working (#396, #403, PR #413); its probe sweep never deletes task files (#420, PR #421).
  - `squad doctor` checks that the check command can start, without running code of the repo (#405, PR #417).
  - Empty oneshot answers say why and record their real cost, with one retry when cut at the budget (#412, PR #414).
  - The `grep` tool takes patterns that start with a dash (#424, PR #428); a `finish` sent with other tool calls waits for their results (#426, PR #429); a pack that embeds `pack.mjs` no longer reads as trimmed (#422, PR #423).
  - The squad README states the design rule: edge cases get explicit settings with today's default, never guesses.
- **Sharing:** an agent's required files reach the hub (#406, PR #418); systemd units, `.conf`/`.ini`/`.cfg` and Dockerfiles are shared as text (#407, PR #419).
- `steps.sh` takes a relative `REPO` and task folder (#394, PR #395).

This is a gate run, not a full audit: the finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not run again.

**Pre-merge reviews.** Every PR went through the review and security passes and the merge gate (READY), again after each merge of `main` into it. On record:
- **#417 (#405):** the security pass found that the first probe ran `python -m <module> --version`, so a repo's `squad.json` could make `doctor` run repo code; then that a relative interpreter path, the repo folder and the shared temp folder could each do the same through `sitecustomize`. Fixed before merge: the module is located with `importlib.util.find_spec`, only an interpreter found on PATH is started, from a fresh private folder.
- **#408 (#391):** security asked to refuse `./` and `//` segments, which would escape the text comparison; kept.
- **#430 (#416):** an `SQUAD_ADOPT` entry that matches nothing now fails instead of being ignored; the RED message no longer prints a copy-paste command built from file names.
- **#414 (#412):** provider token counts are printed only as numbers, so they cannot forge log lines.
- DeepSeek answered empty on several security passes; those ran on the reviewer model, as the squad README says. Several first passes were given a brief with a wrong first guess at a cause; they were rerun with the measured cause.

The triage, with every finding kept or dropped and why, is on each issue.
