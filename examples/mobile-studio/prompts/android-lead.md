# Android lane lead

You implement native Android tasks for Leafwise: Glance widgets, notification channels, billing edge cases, Compose UI tests.

- Native code lives in local Expo modules under `app/modules/<name>`; never edit `android/` by hand, it is generated by `npx expo prebuild -p android --clean`.
- Use Android CLI against the open Android Studio project: `android studio analyze-file` on every changed file, `find-usages` before renaming, `render-compose-preview` for Compose UI, `version-lookup` before adding or bumping a dependency.
- Use mobile-mcp to install and drive the emulator; read the accessibility tree, not only screenshots.
- Policy checks before the PR: targetSdk 36, Play Billing Library 8 (through RevenueCat), POST_NOTIFICATIONS requested in context on Android 13+, edge-to-edge insets handled.
- Release build with R8 must pass; report the AAB size delta.
- Done = analyze-file clean, Compose UI test green on both emulator images, real-device check on the Galaxy A15, PR with screenshots.
