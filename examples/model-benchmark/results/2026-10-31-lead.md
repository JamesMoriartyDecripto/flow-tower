**2 runs per cell for six models, then a third run for the three finalists (3 runs per cell), 3 tasks per category.** These results pick defaults for `architect` and `lead-judge`; they do not rank the models in general.

**Question.** The unattended lead of #320 is code plus two judgement roles on OpenRouter:
- the **architect** turns an issue into small steps with their `Files:` lines;
- the **lead-judge** keeps or drops each review finding.

Which model should each role use by default?

**Tasks.** All come from Flow Tower work closed the same week, with the files as they were before the fix.

- **Planner** (`tasks/planner/`: `steps-scope`, `temp-cleanup`, `focus-links`): issues #353, #357 and #360. The model reads the fixtures and returns a plan as JSON. The check requires 1-3 items per step, the files the merged fix had to touch, and few steps for the small change; a new runner file must also name `src/cli/squad-local.ts`.
- **Judge** (`tasks/judge/`: `quickfix-removal`, `steps-scope`, `temp-cleanup`): 18 real findings from the #347, #353 and #357 review rounds, with the diff the reviewers saw. The answer key is the lead's decision on the day. Critical findings (real security defects) must match exactly, and the rest must mostly match.

**Run.** `scripts/bench.mjs`, effort low, `data_collection: deny`, read_file on the fixtures only; `scripts/judge.mjs` for the checks. Raw data: [2026-10-31-lead/](2026-10-31-lead). Total spend: $1.76 ($1.33 for the first pass and the judge rerun, $0.43 for the third run).

## The key was corrected once, in the open

The first judge pass (`v1-*` files) used the rule "drop findings on lines this pull request does not change". Under that wording 11 of 12 runs dropped #347 S1, which the lead had kept because the pull request made the hole reachable. The rule now reads "keep if the pull request introduces it, or makes it reachable or worse even on an untouched line".

Two findings turned out contested on review:
- #357 S1: `rmSync` never follows a symlink, so it was harmless;
- #353 S5: newlines in file names.

Both accept either answer. In the planner check, `squad-local.ts` was first required unconditionally; it is now required only when the plan adds a runner file (no plan did).
