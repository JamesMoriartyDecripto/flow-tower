Flow Tower

See the whole structure of an agentic system at once: Flow Tower renders AI agents and multi-agent systems as an interactive 3D tower.

Features

  • One YAML file per system. Easy to write and review, and it lives in the same repo as the agent.
  • Tower of layers. Stack layers like intake, orchestration, specialists, tools, guardrails, memory and models.
  • Nested towers. An agent can contain its own tower; double-click it to dive in.

Quick start

Requires Node 22.13 or newer. The app runs locally on 127.0.0.1. Nothing is uploaded.

Install

git clone https://github.com/JamesMoriartyDecripto/flow-tower.git
cd flow-tower && npm install

First run

cp -R examples/starters/single-agent ~/my-project/tower && node bin/flow-tower.js ~/my-project/tower
