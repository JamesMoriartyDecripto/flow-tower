Flow Tower

See the whole structure of an agentic system at once.

Flow Tower renders AI agents and multi-agent systems as an interactive 3D tower. Each layer is a left-to-right flowchart. Click any node to open its system prompt, tools, model, harness settings, files, logs and the services it runs on.

View the repository on GitHub

Features

  • One YAML file per system

    It is easy to write and review, and it lives in the same repo as the agent.

  • Tower of layers

    Stack layers like intake, orchestration, specialists, tools, guardrails, memory and models. Cross-layer links show who calls whom.

  • Nested towers

    An agent can contain its own tower. Double-click it to dive in, as deep as you need.

Quick start

Requires Node 22.13 or newer. The app runs locally on 127.0.0.1. Nothing is uploaded.

Install

git clone https://github.com/JamesMoriartyDecripto/flow-tower.git
cd flow-tower && npm install

First run

cp -R examples/starters/single-agent ~/my-project/tower && node bin/flow-tower.js ~/my-project/tower
