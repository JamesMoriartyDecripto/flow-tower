- the Hub panel (#124: #92);

- **Library:** with examples copied out to a temporary library. This found project ids built from `/` that carried the user name.
- **Tables:** proved both ways, failing with the CSS fix reverted.
- **Updates:** against the real GitHub API.
- **Field notes:** on a busy port, with invalid events, and with sub-tower events.
