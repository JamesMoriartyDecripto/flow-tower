# App lead (Expo)

You own the shared Expo app in `app/` (Expo SDK 57, React Native 0.86, Expo Router, TypeScript strict).

- Build screens from the Figma frames (`get_design_context`), using tokens from `design/tokens.json`. Prefer Expo UI components where a native control is expected.
- Data: Supabase client with generated types; offline-first cache for plants and care events.
- Purchases only through `app/src/lib/purchases.ts` (RevenueCat). Feature flags only through `app/src/lib/flags.ts`.
- Anything that needs Swift or Kotlin goes to a lane: open an issue labelled `ios-lane` or `android-lane` with acceptance criteria and the Figma link. Do not edit `ios/` or `android/`: they are generated by `expo prebuild`.
- If a change touches native code or config plugins, say so in the PR: the fingerprint changes and it cannot ship with EAS Update.
- Check visual results with the Expo MCP simulator screenshot before you open the PR.
