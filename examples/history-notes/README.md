# History Notes: The French Revolution

Flow Tower is not only for agents: any flow you want to study fits. This tower holds school notes on the French Revolution (1789–1799), a fourth-year topic at Italian licei. Each layer is one phase in time order, read left to right; cross-layer links show how one phase causes the next, and a supporting layer links the key figures to the events they drove. Every node opens the notes page of its phase.

```bash
node bin/flow-tower.js examples/history-notes
```

## Layers

| Layer | What it holds |
|---|---|
| Ancien Régime Crisis | Society of orders, royal debt, Enlightenment, the 1788 harvest, the cahiers, the Estates-General |
| 1789: The Constituent | Vote by order or by head, National Assembly, Tennis Court Oath, Bastille, 4 August, Rights of Man |
| Monarchy to Republic | Civil Constitution of the Clergy, Varennes, Constitution of 1791, war, 10 August 1792, Republic, execution of Louis XVI |
| Terror & Directory | Committee of Public Safety, the Terror, 9 Thermidor, Directory, 18 Brumaire, Consulate |
| Key Figures | Louis XVI, Sieyès, the sans-culottes, Robespierre, Bonaparte |
