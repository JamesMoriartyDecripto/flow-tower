# Release gates: Flow Tower v0.19.0

Release candidate: `release/v0.19.0`, on top of `main` at `fd31257` (#463), checked on 2026-11-23. Merged since v0.18.0: #445, #455, #459, #463.

This minor release makes the dev squad's unattended runner finish an issue end to end. It also adds an embed mode for the static build and gives the squad new model defaults, measured on real pull requests.

- **Dev squad autopilot runs end to end** (#462, PR #463):
  - The fix step carries lead-judge's reason for each kept finding.
  - A plan step can name the files it only reads.
  - The worktree is `<repo>-squad/<n>`, beside the repo, and gets `commands.setup` (`npm ci`).
  - Test runs no longer light a running viewer.
  - Two test issues ran through it, #460 and #466, and opened draft PRs #465 and #467. A fix round driven with the real lead-judge, `fixTask` and `steps.sh` followed the judge's reason, which is the case that failed before.
- **Dev squad gate and review** (#449, #452, #453, #456, #457, PR #459):
  - The gate decides on finding severities.
  - Diffs start from the merge base.
  - Role logs sit beside the cost ledger.
  - A shared coding-standards skill goes to the coder and the reviewer.
- **Model defaults** (#447, PR #455). Reviewer and security move to `minimax/minimax-m3.1-flash`, and the lead-judge to `google/gemini-4-carbon`. Both were measured on four real pull requests of this repository.
- **Embed mode** (#444, PR #445). `index.html?embed=1` turns the simulator off and exposes `window.flowTowerEmbed`.
- **Dev Squad tower.** It now draws every exit, refusal, retry and cap of the squad code, checked against the code by fresh reviewers. The code gaps found on the way are in #464.

This is a gate run, not a full audit. The finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not run again.

**Where it ran.** An Intel Mac on macOS 13.
- e2e: the plain `npm run e2e` with `FLOW_TOWER_E2E_GPU=1` and one worker, so [e2e.log](e2e.log) is this run.
- Gates: run with a scratch user folder, so their live events reached no server.
- semgrep: `gates.sh` failed on it, because semgrep ships no Intel macOS binary since 1.183.0. The same configs and arguments ran by hand on semgrep 1.182.0.
- gitleaks: 8.30.1, from the official release with its checksum checked.
