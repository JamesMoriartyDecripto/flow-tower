# Release gates: Flow Tower v0.4.0

Release candidate: `main` with PR #58, #60, #61, #64 and #66, checked on 2026-10-10. This is a gate run, not a full audit: the
finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not run again. The voice work (#62, #63) had its own review
inside its PRs: a dev-squad reviewer and security auditor in two rounds, and a fresh verifier (see PR #64).

| Step | Result |
|---|---|
| tsc, vitest (181 tests), examples validation (0 errors, 0 warnings) | clean |
| semgrep (p/javascript, p/typescript, p/react, p/nodejs, p/secrets) | clean |
| npm audit (high and critical) | 0 (the low-severity KaTeX advisory of v0.3.0 remains, see CHANGELOG § Security) |
| gitleaks over the whole history (`--log-opts=--all`) | no leaks |
| Playwright (30 towers, live, OTLP, layout, camera, export, viewer, axe) | **49 / 49 passed** ([e2e.log](e2e.log)) |

Security fixes found during this cycle are listed in the CHANGELOG (§ Security of 0.4.0): exact content-type checks and
cross-site refusal on every write and read endpoint, secret files never served by `/api/file`.

Not covered by automated tests: the microphone itself (the widget is exercised through its transcript path, and a real
transcription was checked by hand against OpenRouter), and spoken playback in Firefox and Safari.
