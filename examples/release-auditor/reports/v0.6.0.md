# Release gates: Flow Tower v0.6.0

Release candidate: `main` at 02c8446, checked on 2026-10-11. It holds the team-hub stack (#87, #88, #89, #96, #100,
#112: issues #81–#84, #90, #91), its towers and guides (#103, #106, #107, #111: #98, #104, #101, #110), the audit
pass (#114), the skills (#117: #116), the model-benchmark tower (#109: #108) and the squad tooling (#102, #115: #75,
#113). This is a gate run, not a full audit: the finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not
run again.

Each PR had its own dev-squad review: the coder on DeepSeek, the reviewer on GLM 5.3 FlashX, security on DeepSeek, and
the verifier on Claude. The security pass on the satellite relay (#91) led to three fix rounds before merge:
- an allow-list of event fields instead of a drop-list;
- a self-loop guard;
- a body cap on `/api/sharing`, a rate limit on `/api/heartbeat`, and relays stopped on server close.

What the gates caught before merge: the e2e file sweep found two `team-hub` nodes pointing at folders (404 from
`/api/file`). They were fixed in #103. CI runs only `npm run check`, so this was the first e2e run over the
merged stack. #118 makes `validate` catch it.

Checked by hand on a real server: a hub on a Linux host, reached over an SSH tunnel, and a laptop satellite relaying
to it. All 50 test events arrived (25 `tool.start`, 25 `tool.end`). The hub received only metadata fields (kind,
session, user, host, agent, tool, call, status), with no prompt text and no tokens.

Known and open:
- Dependabot alert #1 (low): KaTeX 0.16 prototype-pollution trust bypass. KaTeX is pinned `^0.16` by `rehype-katex`
  and `micromark-extension-math`, so the fix needs an override (#119). It is below the `npm audit` gate (high).

Not covered by automated tests:
- the hub kit's deploy files (systemd unit, docker compose, Caddy), which have not run on a real server (#97);
- Tailscale identity, which needs a tailnet;
- the microphone itself, and spoken playback in Firefox and Safari.
