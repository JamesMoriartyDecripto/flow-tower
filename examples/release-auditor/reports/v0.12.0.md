# Release gates: Flow Tower v0.12.0

Release candidate: `release/v0.12.0`, on top of `main` at `dbf0be3` (#274), checked on 2026-10-21. Merged since v0.11.0: #230, #232-#248, #250-#255, #257-#263, #267-#272, #274. What it holds:
- **The audit reads stated facts** (#249, PR #271): `effect`, `model_varies`, edge conditions, `status` and what a sub-tower inherits from the towers that open it; on the example towers 114 findings before, 33 after. `audit --json` into a pipe is no longer cut at 64 KB.
- **The example towers optimized with the tower optimizer** (#231, PRs #232-#254, #258) and **the models per node from the 2026-10-16 benchmark** (#260, #274): 30 switches in 18 towers, co-scientist's retired `gemini-2.0-flash` and airline-support's `gpt-4.1-mini` (which the benchmark could not run under its data policy) replaced, a new guard task `airline-jailbreak`.
- **Role catalogue** (#261, PR #262): a measured pick and two alternatives from other families for every node role, and `models.mjs --role`; the benchmark calls every OpenRouter endpoint a role needs.
- **Dev squad kit** (#265, PR #267): `squad init`, `squad key` and the `flow-tower-squad` skill run the squad on any git project; the project's commands no longer see `OPENROUTER_API_KEY`.
- **File viewer: SQLite databases and `.sql` schemas as tables** (#264, PR #269).
- **Share and unshare from the interface** (#266, PR #270): a Share with hub menu on each local library card of a satellite, Settings › Sharing with Unshare.
- **New example `ai-commercialista`** (#228, PRs #255, #258) with its own benchmark task sets.
- **Tool fixes:** `check-example` false positives (#229, PR #230), `judge.mjs` command checks on Node 24 (#256, PR #257).
- **On the release branch:** `.gitleaksignore` keeps the one gitleaks finding, the fake OpenRouter key `squad-key.test.ts` writes (#265), checked by hand.

This is a gate run, not a full audit: the finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not run again.

**Where it ran.** The Fedora laptop (Intel Iris Xe, 7.4 GB RAM): the plain `npm run e2e` with `FLOW_TOWER_E2E_GPU=1` and one worker, so [e2e.log](e2e.log) is this run. The gates ran with a scratch user folder, so their live events reached no server.
