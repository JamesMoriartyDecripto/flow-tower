# Leafwise studio conventions (loaded by every session)

- Repo: `app/` (Expo SDK 57, React Native 0.86, Expo Router, TypeScript strict), `app/targets/` (iOS native targets), `app/modules/` (local Expo modules, Kotlin), `backend/` (Supabase SQL and Edge Functions), `store/` (listings per locale), `qa/` (Maestro flows, device matrix).
- `ios/` and `android/` are generated by `npx expo prebuild --clean`. Never edit them by hand.
- Lanes: the app lead owns TypeScript; the iOS lane owns `app/targets`; the Android lane owns `app/modules`. Cross-lane changes go through the shared contract (`app/src/types/supabase.ts`).
- Tokens only (`design/tokens.json`); touch targets 44 pt / 48 dp; every interactive element has an accessibility label.
- Permissions are requested in context, never on launch, and always with a purpose string.
- Entitlements come from RevenueCat; flags from Remote Config with safe defaults.
- OTA (EAS Update) is for JavaScript bug fixes only, never new features, and only when the fingerprint is unchanged.
- Secrets: never in code, app config, logs or prompts. Credentials are referenced by environment variable name; see `credentials/README.md`.
- Definition of done for a release: QA gate green, privacy forms match the SDK inventory, PO sign-off, crash guard armed.

## Store rules learned (appended by the rejection responder)

- 2026-09-30, App Store 3.1.2: the paywall must link Terms of Use (EULA) and Privacy Policy, and the App Store description must include the Terms of Use link.
- 2026-06, App Store 2.1: always provide a working demo account in review notes; the reviewer cannot create one behind our email verification.
- 2026-04, Play Data safety: declare crash logs as collected even though Crashlytics is "only diagnostics".
