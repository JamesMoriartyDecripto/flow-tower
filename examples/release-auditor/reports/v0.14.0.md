# Release gates: Flow Tower v0.14.0

Release candidate: `release/v0.14.0`, on top of `main` at `3d9dbf3` (#326), checked on 2026-10-27 and 2026-10-28. Merged since v0.13.0: #278, #297, #298, #300, #302, #306, #310-#312, #314, #318, #321, #325, #326. What it holds:
- **The dev squad you can trust as shipped** (#322, PR #325).
  - Reviewer and security answer in one request with the code packed by default, and only with the JSON verdict the merge gate reads.
  - The defaults were measured on the squad's own runner: 540 runs, scored with the gate's own code.
  - A fresh project went from `squad init` to a real security finding, kept and fixed, for $0.0121 ([results](../../model-benchmark/results/2026-10-27-squad-roles.md)).
- **Security: the runner never runs a CLI named by a repo it does not live in** (#324, PR #326). Pointing `run.mjs --repo` at someone else's worktree by hand ran the event CLI that worktree's squad.json named. The PR steward already avoided it; now the runner does. It came up as a high finding of the steward's security pass on the handoff PR, and was fixed before this release instead of shipping as a known issue.
- **Squad tooling:**
  - a local PR steward that reviews and gates every open pull request (#319, PR #321);
  - a script merge gate with quoted, checked findings (#299, PR #300);
  - cut answers fail the run (#316, PR #318);
  - simplicity rules and a dependency check in every harness of the dev-squad example (#315, PR #314).
- **New examples:**
  - `tutorial-studio`: a narrated video tutorial as a tower and as runnable scripts (#308, PR #311);
  - `agent-council` (PR #310).
- **App:** the tower card in the tower view (#295, PR #297); long tower names wrap (#301, PR #302).
- **Fixes:** `export --pdf` with JSON files in the appendix (#277, PR #278).
- **Docs:** the command-center kit's update steps (PR #298), the handoff (PR #306, #312).
- **On the release branch:** two docs lines still named the old reviewer default: the `dev-squad` example's pointer to the kit and the benchmark's candidate list.

This is a gate run, not a full audit: the finders and the adversarial verifier of [v0.1.0](v0.1.0.md) did not run again.

- Gates: run with a scratch user folder, so their live events reached no server.

**Pre-merge reviews.** Every PR went through the review and security passes and the merge gate. Since #321, the PR steward runs them as well. On record:
- **#325:** the steward found two real bugs that the lead's review had missed, both fixed before merge:
  - a reply with two prose reports used up both verdict asks;
  - the steward's cost summed amounts printed by the model.
- **#325, live proof of the second fix:** the `main` steward reported one pass at $10.01, while the ledger said $0.02.
- **#326:** steward READY. Its medium finding (a `--loop` pass on a PR's worktree still runs that PR's check) is by design and now documented.

The triage is on each issue.
