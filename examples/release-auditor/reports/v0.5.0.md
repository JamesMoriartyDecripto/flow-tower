# Release gates: Flow Tower v0.5.0

Release candidate: `main` with PR #77 (#68, #72, #73, #74), #78 (#70) and #79, plus #76 (the update-check fix),
checked on 2026-10-10. This is a gate run, not a full audit: the finders and the adversarial verifier of
[v0.1.0](v0.1.0.md) did not run again.

Each PR had its own dev-squad review:
- **#77:** three rounds of a fresh reviewer and a fresh security auditor, then a fresh-context verifier. Round 2 of
  security found the symlinked-tower-file leak, fixed before merge.
- **#78 and #79:** a mixed-model squad, with the coder on DeepSeek, the reviewer on GLM 5.3 FlashX, security on
  DeepSeek, and the verifier on Claude.

| Step | Result |
|---|---|
| tsc, vitest (241 tests), examples validation (0 errors, 0 warnings) | clean |
| semgrep (p/javascript, p/typescript, p/react, p/nodejs, p/secrets) | clean |
| npm audit (high and critical) | 0 |
| gitleaks over the whole history (`--log-opts=--all`) | no leaks |
| Playwright (30 towers, live, OTLP, layout, camera, export, viewer, axe, voice) | **52 / 52 passed** ([e2e.log](e2e.log)) |

Security fixes of this cycle are in the CHANGELOG (§ Security of 0.5.0):
- the tower loader never reads secret files or the user folder, including through symlinked tower files and folders;
- journal and memory files are git-ignored and denied by the dev server;
- accepted voice notes are capped and framed as preferences.

Measured by hand on the real server:
- **First audio of agent replies:** 1.9–2.9 s before, about 0.6 s now.
- **First real sentence:** 1.8 s on Gemini 3.5 Flash-Lite, against 2.4 s on the previous model.

These are illustrative numbers from one run each.

Not covered by automated tests: the microphone itself (the widget is exercised through its transcript path), and
spoken playback in Firefox and Safari.
